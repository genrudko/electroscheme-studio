# Patch 051 — professional Visio/Compass-like UI pass

## Scope

UI-only skin pass. No editor logic, equipment model, drag/drop logic, or renderer logic is changed.

## Goals

```text
Ribbon closer to Visio-style tool chrome
left stencil/palette cleaner and more professional
right properties panel less toy-like
canvas background closer to a CAD workspace
rulers and guides visible but auxiliary
selection/handles more precise
scrollbars and drag ghost polished
decorative placeholder labels hidden
```

## Important

This does not implement exact VSDX master rendering. It only makes the current working UI less prototype-like.
