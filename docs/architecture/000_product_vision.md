# Product Vision

## Name

ElectroScheme Studio

## Goal

Create a local WebUI editor for electrical schemes where the visual diagram is backed by an engineering model.

The application should help users create clear electrical schemes with ГОСТ-oriented symbols and export them to document-friendly formats.

## Non-goals for early stages

- DWG support;
- CAD replacement;
- PDF/image recognition;
- universal automatic layout;
- full formal ГОСТ/СТО validation;
- cloud collaboration.

## First useful result

A local WebUI that can:

- open an example scheme;
- render it as SVG;
- show a sheet/grid;
- display smart symbols;
- allow element selection;
- show properties in a side panel;
- save/load JSON project data;
- export later to SVG/PDF/JPEG.
