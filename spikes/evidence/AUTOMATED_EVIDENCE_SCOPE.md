# Automated desktop evidence scope

The exact-head workflow may claim only the following automated gates:

- locked dependency installation and zero known npm audit findings for the committed lock;
- shared canonical-core tests and deterministic logical outputs;
- Windows and Linux Tauri compilation and Electron/Tauri portable packaging;
- archive/restore integrity of the downloadable candidate layouts;
- packaged in-app canonical, clipboard, PDF, Python and VSDX/VSSX scenarios;
- startup-to-renderer-ready and process-tree RSS measurements on the named GitHub-hosted runners;
- package/archive size and toolchain evidence;
- cross-platform equality of canonical JSON, clipboard, PDF and generated VSDX hashes.

These results are runner-specific engineering evidence, not universal performance claims. They do not close native interactive dialog/drag-drop/print behavior or Microsoft Visio open/edit/save acceptance. Those remain respectively:

- `OWNER_OR_INTERACTIVE_RUNNER_EVIDENCE_REQUIRED`;
- `OWNER_OR_WINDOWS_VISIO_EVIDENCE_REQUIRED`.
